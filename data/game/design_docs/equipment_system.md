# 星港行动：装备系统设计说明

版本范围：1.2至1.3
模块：装备系统、背包系统、资源加载
平台：Android、iOS、Windows

## 装备切换流程

玩家在背包页面选择新装备后，客户端先校验装备归属与等级限制，再异步加载模型、贴图和特效资源。资源加载完成后才能替换角色模型，并向服务端提交装备状态。客户端不得在资源句柄为空时执行模型替换。

Android低内存设备可能在后台回收尚未使用的装备资源。快速连续切换装备、加载过程中退出背包、弱网状态下重复点击确认，都可能使异步回调顺序发生变化。实现层必须验证页面生命周期、资源句柄和当前装备请求编号。

## 错误处理

错误码 E-EQP-500 表示装备模型资源句柄为空。出现该错误时应记录设备型号、系统版本、游戏版本、目标装备ID、资源请求ID和页面生命周期状态。客户端应停止本次模型替换并恢复上一件可用装备，不得继续访问空资源。

## 性能要求

普通设备装备切换应在800毫秒内完成。低内存设备允许降级到静态预览图，但不能导致客户端崩溃。重复点击必须通过请求编号和按钮节流处理。
